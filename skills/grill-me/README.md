# grill-me

A self-contained interviewing skill for stress-testing plans and designs through one question at a time, recommended answers, and a decision tree with a clear stopping condition.

## Acknowledgments

Adapted from Matt Pocock's [grill-me](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md) and [grilling](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md). This version keeps the interview in one skill and preserves one-question-at-a-time interaction without requiring the upstream `grilling` skill or a sub-agent tool.
