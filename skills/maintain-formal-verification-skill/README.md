# maintain-formal-verification-skill

Upkeep pass for a project's formal verification after the code changes without it, such as one generated by `create-formal-verification-skill`. It reads every commit that touched verified code since the last sync, updates the model, harness, or properties from the code, reruns, shows that an updated check can still fail, and says whether each failure is drift in the verification or a bug in the code. Each check ends with an outcome: in sync, updated, bug, or blocked.

Edits stay inside the verification and the verify skill. Product code in the user's checkout is left alone unless the user asks, and a property is never weakened to make a check pass.

People and agents can both invoke it on every supported host. The description names only explicit requests, so ordinary discussion should not start it.

## Source

Adapted from [Cursor's pstack `maintain-formal-verification-skill`](https://github.com/cursor/plugins/blob/ae5650febf4320793844c12c4adaa937f417f8da/pstack/skills/maintain-formal-verification-skill/SKILL.md). Local adaptations:

- Verify-skill discovery names common project skill directories, because upstream relies on an adapter file this import does not include.
- The temporary break runs in a temporary worktree or copy, so the user's checkout and uncommitted work stay untouched, and the rerun step separates hand-written models from verifiers that run on the code.
- A verify skill or harness that changed since the sync commit is read and confirmed with the user before it runs, and a commit message alone no longer justifies changing a property.
- Counterexample replays stay local or disposable, and the verification change stages only verification files.
- `disable-model-invocation: true` removed, so people and agents can invoke it on every host. OpenCode ignores the field, so explicit-only behavior could not hold everywhere.
- The description drops upstream's broad trigger clause, because the description now decides when agents start the skill.
- `license: MIT` added to the frontmatter.
