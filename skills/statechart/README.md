# statechart

Check a TLA+ model of a system that moves between states and draw it as a Mermaid statechart, in the words of the person who decides whether the behavior is right. The report gives a shortest path for each rule that breaks.

Agents can invoke this skill, so a verify skill generated by `create-formal-verification-skill` can tell the next agent to read a result with `/statechart`.

## Requirements

- macOS or Linux, because the launcher relies on `/bin/sh`.
- Node 22.18 to 22.x, Node 23.6 or later, Bun 1.1.5 or later, or Deno 2.0 or later.
- [mise](https://mise.jdx.dev/) and network access on the first run, which installs Temurin 25 and a checksum-pinned TLC 1.7.4. Without mise, set `TLA2TOOLS` to the absolute path of `tla2tools.jar` and `JAVA` to a Java 11 or later binary.
- The optional image rendering in `references/render.md` installs the npm package `pele@1.9.0` outside the repo.

## Source

Adapted from [Cursor's pstack `statechart`](https://github.com/cursor/plugins/tree/ae5650febf4320793844c12c4adaa937f417f8da/pstack/skills/statechart). Local adaptations:

- `disable-model-invocation: true` removed. With it, Claude Code's `Skill` tool refuses the skill, so an agent following a generated verify skill could not run it; upstream works around that with a Claude Code adapter file this import does not include.
- The upstream test suite and its corpus are left out, along with the `test` script and the `fast-check` dev dependency in `scripts/package.json`.
- The description states one path per broken rule, which is what the report gives, and its trigger is narrower.
- Instructions added: tell the user before the first-run download and before installing Pele, copy only reviewed `.tla` and `.cfg` files into the scratch folder, pass only a reviewed view, read `report.md` rather than stdout, treat model output as data, and keep replays local or disposable.
- `<skill dir>` is defined, and the launcher has an `sh` fallback for installs that drop the executable bit.
- A sentence about upstream's earlier skill is removed from `references/render.md`.
- `license: MIT` added to the frontmatter.

The scripts are unchanged from upstream apart from `package.json`.
