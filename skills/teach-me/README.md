# teach-me

A picture-led introduction to an unfamiliar topic, delivered as a focused HTML explainer.

The name emphasizes learning without implying a literal age. This remains a focused explainer, rather than a full tutoring or course system. It can be used on its own; `show-me` complements it when the user also wants help choosing a visual representation.
