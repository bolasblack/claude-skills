# Writing for Agents

Keep required context next to the action it governs, give every workflow step a
locally checkable completion criterion, preserve the existing output contract, and
remove prose that does not change an agent decision. Do not take ownership of package
scope, executable mechanics, tests, or release policy from the primary authoring skill.
