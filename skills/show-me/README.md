# show-me

Make the structure, flow, or change under discussion visible through concise diagrams, code-shaped sketches, or a focused HTML artifact.

This skill chooses a useful representation at the user's existing level of understanding. `teach-me` instead organizes a beginner-friendly explanation. Each skill works independently; together, the lesson sets the learning goal and the visuals support it.
